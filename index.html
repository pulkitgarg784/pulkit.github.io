About

Hi! I love building cool interactive experiences and my experience spans C++, Vulkan, OpenGL, Game Development using Unity/Unreal Engine, and Virtual Reality.

I'm currently a Graphics Programming Intern at SideFX, working on performance-critical, cross-platform rendering for Houdini. I built core Vulkan viewport functionality, which included creating multiple Vulkan libraries and a GPU text-rendering pipeline using bitmap fonts and texture atlases.

Earlier, I improved high-precision data imports, mesh-decimation algorithms, and real-time modeling workflows at SideFX R&D, and built VR training software for wind-turbine technicians at Liftwerx. Before that I worked on Android Automotive OS and real-time 3D vehicle visualization at Ford Motor Company using C++, Kotlin, and Google Filament.

Back in high school, I founded and led Sojourn Interactive, a game studio focused on socially impactful games in Unity, from 2019-2023.

In my free time you'll find me making digital 3D art, cooking, playing Kerbal Space Program, or at a hackathon.
